# Electronic tables

Four files are supplied with the manuscript's identifiers. S1 is not bundled: optional published/recomputed rows require user-supplied input. S2: Thin-layer valid counts, coverage, conditional probabilities and intervals. S3: Three-seed noise-distribution summary (seed extrema are not confidence intervals). S4: Deterministic device-specification comparison. S9: Literature comparison and source-access limits. S9 is an archived identifier; no S5–S8 electronic files are asserted.

SCHEMA.csv enumerates columns and units of shipped tables; the optional E1 header is documented separately. `_m`, `_mm`, `_deg` and `temperature_C` designate metres, millimetres, degrees and Celsius. Probabilities, coverages, ratios and return proxies are dimensionless; counts/seeds/stream identifiers are integers. `kappa` is the dimensionless off-normal loss coefficient in exp(-kappa*tan(theta)^2), not a thickness-dependent attenuation coefficient; `rho_rel`, `n_diffuse`, `Q_scale`, `p` and `q` are dimensionless. N is attempted count per class; valid counts define conditional denominators. Empty/nonfinite conditional cells denote no valid denominator, not zero probability. S9 U means not established from accessed material, not absence. Other S9 columns are categorical prose; Year is publication year.

Source mapping is in docs/TABLE_REPRODUCTION_MAP.csv. Values/precision are unchanged. S1 remains an optional local output and is excluded from this package. S2–S4 derive from stored author model outputs; S4 references Garmin specification magnitudes without reproducing the manual. S9 is author literature synthesis, not copied source text. See docs/THIRD_PARTY_REFERENCES.md for citations and limitations.

S4 and S9 are mixed provenance: manufacturer/source facts plus original author analysis/synthesis, with no reproduced source text/table layout.
